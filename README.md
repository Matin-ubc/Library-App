# Library App

## Getting Started

Place the Library application on your desktop and make sure you do not delete the database file that is automatically created when you first open the application.

If Python is not already installed on your computer, install the latest version of Python before running the application.

## Initial Setup

When using the application for the first time, you need to complete a few initial actions before most of the features become available:

1. Add at least 1 book to the library.
2. Add at least 1 member.
3. Borrow the book and return it.
4. Repeat the borrowing and returning process 3 times.

After completing these steps, most of the application's functions, including statistics, will be available.

## Using the Application

Some functions may not produce results during the first few uses because they depend on data being generated through normal use of the application.

For example, when the available quantity of a book reaches 0, the application will provide the user with the exact date when the selected book will next be available to borrow.

As you continue using the application and more data is recorded, additional functions and features will become available.

## Database File

The application automatically creates a database file in its original directory. Do not delete or move this file, as it contains the information required by the application.

To keep the database file out of sight on your desktop, create a shortcut to the Library application and place the shortcut on your desktop instead of moving the original application files.

## Requirements

Make sure the latest version of Python is installed on your computer before running the application.
